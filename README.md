# Vanilla JS Web Development & Algorithm Lab

A collection of lightweight, production-grade micro-applications, interactive UI components, and data-structure engines built entirely in **Vanilla HTML5, CSS3, and modern JavaScript (ES6+)**—with zero heavy frameworks or external build toolchains.

## 🚀 Project Architecture

Each project is isolated in its own self-contained directory containing its layout, styling, execution logic, and visual preview asset:

```text
├── 01-Stopwatch-Lap-Tracker/
│   ├── index.html     # Semantic markup structure
│   ├── style.css      # Custom modern CSS styling & layouts
│   ├── script.js      # Core logic & high-resolution performance timers
│   └── screen.png     # Visual component thumbnail
├── 02-.../
└── server.js          # Dynamic Express web server hosting all modules
```
